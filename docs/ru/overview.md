# Findrail: локальная альфа

Findrail ищет буквальные слова в явно выбранных папках с заметками, кодом и
текстовыми PDF. Показывает найденный фрагмент, сохранённый текст документа,
источник и страницу PDF. Индекс и документы остаются локальными; индекс содержит
обычный незашифрованный текст и пути.

**Последняя опубликованная версия — `0.1.0-alpha.2`. Alpha.3 пока кандидат и не
доступна для скачивания.** Не считайте будущие функции уже выпущенными. См.
[матрицу версий](../launch/press-kit.md#version-boundaries).

## Что уже работает

В опубликованном alpha.2: поиск по выбранным локальным папкам, предпросмотр,
страницы текстовых PDF, обновление индекса при запущенном приложении, CLI,
веб-интерфейс на loopback и демо из трёх вымышленных документов.

В main/candidate alpha.3 дополнительно есть управление источниками в UI, bounded
DOCX body text, snapshots публичного GitHub, portable snapshots, отчёты
индексации, root-only `.findrailignore`, коллекции доказательств, `evaluate`,
MCP и экспериментальный connector kit. Эти функции не входят в архив alpha.2.
Подробные ограничения перечислены в [таблице версий](../launch/press-kit.md#version-boundaries).

## Установка опубликованного alpha.2

Скачай архив подходящей ОС/архитектуры со страницы
[Releases](https://github.com/Lephiziel/findrail/releases), проверь его SHA256 по
`SHA256SUMS.txt` именно этого выпуска и распакуй. Go не нужен. Архивы не
подписаны; для macOS может понадобиться разрешение только для этого приложения
в Privacy & Security. Не отключай общесистемную защиту.

```bash
./findrail demo
```

Введи `idempotency`, открой Preview для `webhook-runbook.pdf` и проверь страницу
2. Оригинальный путь копируется; браузер не открывает локальный `file:` как
настольное приложение. Останови демо через Ctrl+C. Демо и видео показывают более
узкий старый workflow alpha.2, а не новые функции alpha.3.

Alpha.2 не включает новый сценарий Add folder. После фактической публикации
alpha.3 ожидаемый первый путь: архив → checksum → распаковка → пустой запуск →
Add folder → поиск технического документа → Preview/PDF page → две точные цитаты
с заметкой → Markdown download → restart. Он не требует сначала настраивать MCP,
GitHub, VS Code или собирать программу из исходников. До публикации смотри
[инструкцию установки кандидата](../../build/package/INSTALL.txt), не считай её
ссылкой на скачивание. Один ручной smoke занимает примерно 10–15 минут:
[лист проверки](../release-smoke-alpha3.md).

## Обновление и удаление

У alpha.2 схема индекса 2; кандидат alpha.3 использует schema 6 и прямые
миграции 1–6. Перед обновлением останови все процессы Findrail и скопируй весь
каталог данных, включая WAL/SHM при наличии, в отдельное место. У старых
источников DOCX выключен по умолчанию. Обратных миграций нет: старый binary
нельзя запускать на schema 6. Для отката восстанови полную резервную копию в
отдельный каталог и используй совместимую с ней версию. Для удаления останови
все процессы и удали каталог приложения; каталог индекса удаляй отдельно и
только если сохранённый текст больше не нужен. Исходные файлы не меняются.
Полные команды и варианты путей с пробелами — в [INSTALL.txt](../../build/package/INSTALL.txt).

## Ограничения

Сканированные PDF требуют OCR, которого нет. Поиск буквальный, не семантический.
GitHub — только публичные файлы с ручным обновлением. Portable snapshot содержит
индексированный plaintext и provenance, не оригинальные файлы и не копию
database; импорт заморожен. Отчёт показывает последнюю успешно сохранённую
индексацию, а не историю ошибок. Коллекция существует только в текущей вкладке и
исчезает после reload. `evaluate` сравнивает Literal-наборы путей: 1–100 кейсов,
до 100 результатов на кейс; incomplete — ошибка, mismatch даёт ненулевой код
после полного отчёта.

VS Code VSIX — отдельная локальная установка с Findrail server/client API v1;
Marketplace и Open VSX не опубликованы. Connector kit экспериментальный,
независимое adoption не подтверждено. Ни эти функции, ни native package CI не
означают сертификацию всех браузеров, редакторов или платформ.
