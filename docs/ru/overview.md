# Findrail: локальная альфа

Findrail ищет буквальные слова в явно выбранных папках с заметками, кодом и
текстовыми PDF. Показывает найденный фрагмент, сохранённый текст документа,
источник и страницу PDF. Индекс и документы остаются локальными; индекс содержит
обычный незашифрованный текст и пути.

**Последняя опубликованная версия — [0.1.0-alpha.3](https://github.com/Lephiziel/findrail/releases/tag/v0.1.0-alpha.3).** Это
тестовая альфа. См. [матрицу версий](../launch/press-kit.md#version-boundaries) и
[результаты проверки выпуска](../release-alpha3-verification.md).

## Что уже работает

Локальный поиск по заметкам, коду, текстовым PDF и Word DOCX, предпросмотр,
страницы PDF, обновление папок при запущенном приложении, CLI и локальный
веб-интерфейс. Alpha.3 также включает управление источниками, Advanced-запросы
и фильтры, публичные GitHub-снимки с ручным обновлением, переносимые снимки,
отчёты индексации, `.findrailignore`, коллекции цитат с экспортом Markdown,
`evaluate`, MCP и экспериментальный connector kit. Старые архивы alpha.2 этих
дополнений не содержат.

## Установка alpha.3

Скачай архив своей ОС/архитектуры со страницы [выпуска](https://github.com/Lephiziel/findrail/releases/tag/v0.1.0-alpha.3) и
[SHA256SUMS.txt](https://github.com/Lephiziel/findrail/releases/download/v0.1.0-alpha.3/SHA256SUMS.txt), проверь соответствующий SHA256 и распакуй.
Go, Python и внешний сервер базы данных не нужны. Архивы не подписаны; на macOS
может понадобиться разрешение только для этого приложения в Privacy & Security.
Перед обновлением старого индекса сделай полную резервную копию.

```bash
# Linux / macOS
./findrail start
```

```powershell
# Windows
.\findrail.exe start
```

Открой локальный URL из терминала. Новый индекс пустой: в **Sources** нажми
**Add folder** и укажи абсолютный путь к папке на компьютере с Findrail. Старый
индекс продолжает работу с сохранёнными источниками; для отдельной проверки
задай новый `--data-dir` и используй его при каждом запуске.

Найди слово, открой **Preview**, проверь фрагмент и страницу PDF, если она есть.
Для DOCX номера страниц не заявляются. Добавь две точные цитаты и заметку в
коллекцию и скачай Markdown. Коллекция живёт только во вкладке и исчезает при
перезагрузке; скачанный файл сохраняется отдельно. Останови через Ctrl+C и
перезапусти с тем же каталогом данных. MCP, GitHub, VS Code и сборка из исходников
для этого не нужны. Полная инструкция — в [INSTALL.txt](../../build/package/INSTALL.txt).

Демо запускается через `./findrail demo` (Windows: `.\findrail.exe demo`),
запрос `idempotency` показывает три вымышленных документа и PDF на странице 2.
Старое видео демонстрирует этот более узкий сценарий alpha.2.
[Предыдущий alpha.2](https://github.com/Lephiziel/findrail/releases/tag/v0.1.0-alpha.2)
остаётся доступен для совместимого старого индекса. [Лист ручной проверки](../release-smoke-alpha3.md).

## Обновление и удаление

У alpha.2 схема индекса 2; alpha.3 использует схему 6 и прямые
миграции 1–6. Перед обновлением останови все процессы Findrail и скопируй весь
каталог данных, включая WAL/SHM при наличии, в отдельное место. У старых
источников из alpha.2 DOCX выключен по умолчанию; уже настроенные политики
других источников сохраняются. Обратных миграций нет: старый binary
нельзя запускать на schema 6. Для отката восстанови полную резервную копию в
отдельный каталог и используй совместимую с ней версию. Для удаления останови
все процессы и удали каталог приложения; каталог индекса удаляй отдельно и
только если сохранённый текст больше не нужен. Исходные файлы не меняются.
Полные команды и варианты путей с пробелами — в [INSTALL.txt](../../build/package/INSTALL.txt).

## Ограничения

Сканированные PDF требуют OCR, которого нет. Поиск буквальный, не семантический.
GitHub — только публичные файлы с ручным обновлением. Portable snapshot содержит
индексированный plaintext и provenance, не оригинальные файлы и не копию
database; импорт заморожен. Отчёт показывает последнюю успешно сохранённую
индексацию, а не историю ошибок. Коллекция существует только в текущей вкладке и
исчезает после reload. `evaluate` сравнивает Literal-наборы путей: 1–100 кейсов,
до 100 результатов на кейс; incomplete — ошибка, mismatch даёт ненулевой код
после полного отчёта.

[VS Code VSIX](https://github.com/Lephiziel/findrail/releases/download/v0.1.0-alpha.3/findrail-readonly-0.1.0.vsix) — отдельная локальная установка с Findrail server/client API v1;
Marketplace и Open VSX не опубликованы. Connector kit экспериментальный,
независимое adoption не подтверждено. Ни эти функции, ни native package CI не
означают сертификацию всех браузеров, редакторов или платформ.
